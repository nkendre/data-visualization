# DataVisualization
**Data visualization using Angular and High Charts **
Data visualization, including charts and graphs, is important because it transforms complex data into easily understandable visuals, enabling quicker identification of trends, patterns, and insights, which facilitates better decision-making and communication. 
**High Chart integration**
this assignment is for integration of the Highcharts charting library into an Angular application. Highcharts is a popular JavaScript library used to create interactive and visually appealing charts and graphs for web applications. Angular is a framework for building dynamic, single-page client-side applications using TypeScript.
